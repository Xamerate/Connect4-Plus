__Connect4 Plus__ - простая игра на Unity на двоих игроков, смысл которой - поставить 4 фишки в ряд в любом направлении, первее чем другой игрок

![Static Badge](https://img.shields.io/badge/Version-1.2-green)

__Как установить?__
- Зайдите на сайт [xamerate.itch.io/connect4plus](https://xamerate.itch.io/connect4plus) и скачайте файл для Windows или Android
